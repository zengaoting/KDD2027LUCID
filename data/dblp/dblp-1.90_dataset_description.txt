Dataset Overview
----------
DBLP-1.90 is an academic collaboration network dataset used for Community Detection tasks. This dataset is constructed based on the DBLP (Digital Bibliography & Library Project) academic database and contains authors, collaboration relationships, and real community ground-truth information.

Dataset Scale
----------
- Total Nodes: 114,095 nodes (Node ID range: 0-114094)
- Total Edges: 466,760 undirected edges
- Number of Communities: 4,558 labeled communities
- Node Feature Dimension: No node feature file

- Community Scale Statistics:
  * Average community size: Approximately 8.4 nodes

Note
----------
- There are some nodes in the graph that do not appear in the community labels
- Communities may have overlaps (overlapping communities), meaning a single node may belong to multiple communities
