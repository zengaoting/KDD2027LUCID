Dataset Overview
----------
Amazon-1.90 is a product co-purchasing network dataset used for Community Detection tasks. This dataset is constructed based on product co-purchasing relationships on the Amazon e-commerce platform and contains nodes, edges, and real community ground-truth information.

Dataset Scale
----------
- Total Nodes: 13,178 nodes (Node ID range: 0-13177)
- Total Edges: 33,766 undirected edges
- Number of Communities: 4,516 labeled communities
- Node Feature Dimension: No node feature file

- Community Scale Statistics:
  * Average community size: Approximately 9.3 nodes

Note
----------
- There are some nodes in the graph that do not appear in the community labels
- Communities may have overlaps (overlapping communities), meaning a single node may belong to multiple communities
