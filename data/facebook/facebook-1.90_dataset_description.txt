Dataset Overview
----------
Facebook-1.90 is a social network dataset used for Community Detection tasks. This dataset contains a subgraph of a Facebook social network, including nodes, edges, node features, and real community ground-truth information.

Dataset Scale
----------
- Total Nodes: 3,622 nodes (Node ID range: 0-3621)
- Total Edges: 72,963 undirected edges
- Number of Communities: 129 labeled communities
- Node Feature Dimension: 3-dimensional feature vectors

- Community Scale Statistics:
  * Average community size: Approximately 15.6 nodes

Note
----------
- There are some nodes in the graph that do not appear in the community labels
- Communities may have overlaps (overlapping communities), meaning a single node may belong to multiple communities
