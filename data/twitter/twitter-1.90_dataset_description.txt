Dataset Overview
----------
Twitter-1.90 is a social media network dataset used for Community Detection tasks. This dataset is constructed based on the Twitter social platform and contains users, following relationships, node features, and real community ground-truth information.

Dataset Scale
----------
- Total Nodes: 87,760 nodes (Node ID range: 0-87759)
- Total Edges: 1,293,984 undirected edges
- Number of Communities: 2,837 labeled communities
- Node Feature Dimension: 19-dimensional feature vectors

- Community Scale Statistics:
  * Average community size: Approximately 10.9 nodes

Note
----------
- There are some nodes in the graph that do not appear in the community labels
- Communities may have overlaps (overlapping communities), meaning a single node may belong to multiple communities
- Node features are 19-dimensional numerical features; normalization is suggested before use
