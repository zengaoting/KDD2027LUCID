Dataset Overview
----------
LiveJournal-1.90 (abbreviated as LJ-1.90) is a social blog network dataset used for Community Detection tasks. This dataset is constructed based on the LiveJournal social blogging platform and contains users, social relationships, and real community ground-truth information.

Dataset Scale
----------
- Total Nodes: 69,860 nodes (Node ID range: 0-69859)
- Total Edges: 911,178 undirected edges
- Number of Communities: 999 labeled communities
- Node Feature Dimension: No node feature file

- Community Scale Statistics:
  * Average community size: Approximately 13.0 nodes

Note
----------
- There are some nodes in the graph that do not appear in the community labels
- Communities may have overlaps (overlapping communities), meaning a single node may belong to multiple communities
